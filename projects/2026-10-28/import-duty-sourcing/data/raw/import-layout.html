FILENAME: CONCORD.TXT

FIX FORMATTED ASCII FILE RECORD LENGTH: 235

POSITION FIELD NAME DESCRIPTION
1-10 commodity 10-Digit Harmonized Tariff Schedule (HTS) Code
11-160 descriptn 150-Digit HTS Description
161-210 abbreviatn 50-Digit HTS Description
211-213 unit_qy1 3-digit Unit of Quanitity 1
214-216 unit_qy2 3-digit Unit of Quanitity 2
217-221 sitc 5-Digit SITC Code
222-226 end_use 5-Digit ENDUSE Code
227-232 naics 6-Digit NAICS Code
233-233 usda 1-Digit USDA Code
234-235 hitech 2-Digit HITECH Code

FILENAME: COUNTRY.TXT

FIX FORMATTED ASCII FILE RECORD LENGTH: 61

POSITION FIELD NAME DESCRIPTION
1-4 cty_code 4-Digit Country Code
5-11 cty_desc 7-Digit Country Description
12-61 cty_name 50-Digit Country Name

FILENAME: DISTRICT.TXT

FIX FORMATTED ASCII FILE RECORD LENGTH: 59

POSITION FIELD NAME DESCRIPTION
1-2 dist_code 2-Digit Distrcit Code
3-9 dist_desc 7-Digit District Description
10-59 dist_name 50-Digit District Name

FILENAME: ENDUSE.TXT

FIX FORMATTED ASCII FILE RECORD LENGTH: 105

POSITION FIELD NAME DESCRIPTION
1-5 enduse 5-Digit ENDUSE Code*
6-105 eudesc 100-Digit ENDUSE Description

* Includes 1-, 2-, 3-, and 5-digit end-use codes.

FILENAME: HITECH.TXT

FIX FORMATTED ASCII FILE RECORD LENGTH: 32

POSITION FIELD NAME DESCRIPTION
1-2 hitech 2-Digit HITECH Code
3-32 hidesc 30-Digit HITECH Description

FILENAME: HSDESC.TXT

FIX FORMATTED ASCII FILE RECORD LENGTH: 206

POSITION FIELD NAME DESCRIPTION
1-6 commodity 6-Digit Harmonized Code*
7-156 descriptn 150-Digit Commodity Description
157-206 abbreviatn 50-Digit Commodity Description

* Includes 2-, 4- and 6-digit HS codes.

Portfolio Preview Deployments

A pull request can break an Excel download or a project link while the homepage still loads. This workflow builds the full portfolio and checks the resulting files before the update is published.

What the workflow checks

  1. Rebuild case pages, reports, and downloads in a GitHub Actions job.
  2. Validate local URLs, assets, ZIP contents, and the Crocs and United Rentals Excel models.
  3. Open the site in Chromium at desktop and mobile sizes, use project search, and download an Excel workbook.
  4. Upload the preview ZIP and a build log to the run summary.

Verification

The initial passing run built 31 case studies, checked 818 internal link and asset references, and verified 31 archives. Two local test changes, a broken download link and a package missing an Excel workbook, both failed verification.

Open build results and preview downloads

Preview files are retained for seven days. Open the extracted site using a local HTTP server. Production publication runs separately through ChatGPT Sites.
